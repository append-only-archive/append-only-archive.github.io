Privacy Policy

Last updated: 6 November 2026

Scope and purpose

Paperless Append-Only Archive is a personal, non-commercial archival application. It transfers backup objects from a locally operated Paperless-ngx instance to the authorized user's own Google Drive.

Google user data accessed

The application requests only the https://www.googleapis.com/auth/drive.file scope. It uses this permission to create archive folders and files and to read or update only the objects it created when performing integrity verification or recovery operations.

The application does not request permission to browse or access unrelated files in the user's Google Drive.

How data is used

Google Drive access is used only to:

  • store append-only Paperless-ngx backup objects;
  • store manifests and integrity checksums;
  • verify that previously uploaded objects remain intact; and
  • support user-directed disaster recovery.

Storage and processing

Processing runs on the user's own computer. OAuth credentials are kept in protected local storage. Archive contents reside in the user's own Google Drive and are not stored by the operator on a separate external service.

Sharing and sale of data

Google user data is not sold, used for advertising, or shared with third parties. Use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and user control

The append-only design avoids automated deletion or replacement of archived objects. The user controls retention within Google Drive and may revoke the application's access at any time through Google Account permissions. The application can no longer access Google Drive after authorization is revoked.

Security

The application uses a least-privilege OAuth scope, local execution, restricted local credential storage, and cryptographic checksums for integrity verification.

Contact

Privacy questions may be sent to the support address displayed on the Google OAuth consent screen.
