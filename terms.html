Purpose

Paperless Append-Only Archive is a personal, non-commercial archival application designed to copy backup objects from a locally operated Paperless-ngx instance to the authorized user's own Google Drive.

Authorized use

The application may be used only with Paperless-ngx instances, Google accounts, and Google Drive storage that the user is authorized to access. The application must not be used for unlawful purposes or to access another person's data without permission.

User responsibilities

The user is responsible for:

  • protecting account credentials and local OAuth credentials;
  • maintaining sufficient storage capacity in Google Drive;
  • confirming that source documents and backups are complete;
  • testing recovery procedures independently; and
  • making decisions about archive retention.

Append-only behavior

The application is designed not to automatically delete or replace archived objects. The user retains control of objects stored in Google Drive. The append-only design cannot prevent changes caused by the user, the storage provider, account loss, hardware failure, malicious software, or other external events.
