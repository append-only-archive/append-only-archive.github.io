Paperless Append-Only Archive

Paperless Append-Only Archive is a personal, non-commercial archival application. It exports documents from a locally operated Paperless-ngx instance and stores append-only backup objects in the authorized user's own Google Drive.

Google Drive access

The application requests only the https://www.googleapis.com/auth/drive.file scope. This permits access to files and folders created by the application and does not grant access to unrelated files in the user's Google Drive.

Local and private operation

Processing runs on the user's own computer. Archive objects are sent only to the user's own Google Drive. The application does not use advertising, analytics, tracking, or third-party data sales.

OAuth credentials are kept in protected local storage. Archived documents, manifests, identifiers, credentials, tokens, machine paths, configuration files, and operational logs are not published in this repository.
